# should not itself be written here in plain text (or base64, which is just as readable).
# Each entry is the sha256 of a lowercase token; leak-check hashes every substring of the
# same length in each scanned line and compares. The raw tokens never appear in the repo.
# This deters casual reading and keeps the list from matching itself; it is NOT secrecy — a
# short name or an 8-hex-digit id prefix can be recovered from its hash by brute force.
#
# Format:  <kind> <length> <sha256-hex> <label>
#   word    matched inside one alphanumeric run (case-insensitive), e.g. a name, an id prefix
#   joined  matched after dropping '-', '_', '.' and spaces, so "a-b", "a b", "A_B", "ab" all hit

# GitHub's own URLs, merge titles, branch names and noreply emails would fail CI for good):
# list specific personal forms (full name, joined name, email local part), not a bare surname.
